## 🚀 كيف تستخدمها؟

### 1. شغل النظام
```bash
# Backend
cd hrms-backend
python manage.py runserver

# Frontend (في نافذة أخرى)
cd hrms-frontend
npm run dev
```

### 2. افتح الصفحة
- اذهب إلى: http://localhost:5173
- سجل دخول بحساب Super Admin
- اضغط على "User Management"

### 3. استمتع!
- يجب أن ترى 41 مستخدم
- جرب جميع الوظائف
